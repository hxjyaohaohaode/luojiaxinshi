# 项目共享资料

这些附件用于同学理解项目和继续开发，按原始文件名原样保留。代码直接从仓库根目录启动，无需搬动这些附件。

- `项目内容设计稿/`：项目方案、最小可行版本及历史修订的 Word / PDF。2026-10-14 小米模型版是本次共享的最新模型分工版本；方案中的远期设想不代表已全部实现。
- `平台接口调研文件/`：接口权限调研、不同日期修订及 CSV 核验底稿。平台接口会变化，接入时应重新核验官方条件。
- `官方文件/`：赛事通知与项目需求的已有材料。
- `视觉设计/`：原创应用 Logo、各轮方案与生成提示词、图标预览、用户提供的前端手稿。界面实际使用的资源在 `static/assets/`。

`文件清单.json` 逐个记录附件大小和 SHA-256，可检查下载完整性。原 Word/PDF 没有重新排版；旧版名称不改成新版，避免把历史方案当成当前实现。

本机的两张第三方校徽/建筑参考图片未随仓库再分发，它们不是应用运行依赖；可依据 ASSETS.md 的官方来源核验。外部组件资料目录也不是项目依赖。真实用户上传的通知、私人附件、导出包、账号数据库和密钥不属于公开开发附件，不进入此目录。

当前功能、启动与测试以根目录 README、CONTRIBUTING 和 docs/genui/TESTING 为准。面向公众发行前，项目维护者需确定项目许可证、原创资源的授权范围及校园标识使用方式。
