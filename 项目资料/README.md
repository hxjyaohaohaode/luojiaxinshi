# 项目共享资料

这些附件用于同学理解项目和继续开发，按原始文件名原样保留。代码直接从仓库根目录启动，无需搬动这些附件。目录中只保留各类资料的定稿版本，早期修订已移除，需要时可从 git 历史取回。

- `项目内容设计稿/`：2026-10-14 小米模型版的项目方案和最小可行版本，各有 Word 与 PDF。方案中的远期设想不代表已全部实现。
- `平台接口调研文件/`：平台接口与权限调研定稿 `平台接口与权限调研_2026-10-11`（Word 与 PDF），以及 `核验底稿/` 中 2026-10-11 的官方来源复核、文档回归核验、正反向与一致性复核三份 CSV。平台接口会变化，接入时应重新核验官方条件。
- `官方文件/`：大赛通知与项目需求。
- `视觉设计/`：V4 视觉平衡版应用 Logo、浅底版应用图标、图标尺寸与裁切预览、图标预览页及对应生成提示词，以及用户提供的通用前端视觉与交互开发手稿。界面实际使用的资源在 `static/assets/`；SVG 动效源文件保存在仓库根目录的 `design/motion/`，随源码发布包分发。

`文件清单.json` 逐个记录附件大小和 SHA-256，可检查下载完整性。原 Word/PDF 没有重新排版；设计稿、调研和 Logo 的文件名带日期或版本号，避免把历史方案当成当前实现。

本机的两张第三方校徽/建筑参考图片未随仓库再分发，它们不是应用运行依赖；可依据 ASSETS.md 的官方来源核验。外部组件资料目录也不是项目依赖。真实用户上传的通知、私人附件、导出包、账号数据库和密钥不属于公开开发附件，不进入此目录。

当前功能、启动与测试以根目录 README、CONTRIBUTING 和 TESTING 为准。面向公众发行前，项目维护者需确定项目许可证、原创资源的授权范围及校园标识使用方式。
