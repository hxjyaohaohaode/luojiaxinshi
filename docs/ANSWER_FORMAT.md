# 答复格式兼容与流式边界

模型输出格式属于不可靠输入。工具要求、JSON Schema 与提示词用于减少错误，不能代替接收端兼容、校验和失败恢复。

## 已支持的展示格式

`app/answer_format.py` 为主 Agent 和独立 UI 编排器提供确定性的展示适配：

| 返回形态 | 处理 |
| --- | --- |
| 完整答复 JSON 对象 | 保留字段，通过原有 Schema、引用与结构检查 |
| 单独的 JSON 代码围栏或无语言围栏 | 去掉外层围栏，正文与界面继续增量解码 |
| 带 BOM、空白、CRLF 的完整对象 | 只规范化外层封装 |
| JSON 对象被再次编码为字符串 | 最多解开一层；不猜测内层代码，完整校验后才显示 |
| 普通 Markdown 正文 | 保留正文，包装为 `answer`；没有额外生成调用 |
| 缺失字段、未知引用、重复键、非有限数、截断对象、混杂或有歧义的结构 | 保留错误，不猜缺失事实或代码；相同错误只给一次定向修复机会 |
| 传输正常结束但没有正文和工具调用 | 立即结束本轮，记录实际用量，不进入三轮 JSON 修复 |

正文适配只使用模型实际写出的当前 `[E编号]`。图片和媒体的身份元数据只从这些已登记引用派生，不自动挂接所有附件，不编造原句、claims、记忆维护或成功回执。正文中的手写显示编号和不存在的 E 编号仍会被原有程序检查拒绝。所有事实仍由独立审查读取同一原图核对。

展示适配不会放宽工具参数、用户授权、执行审批、业务回执、账号隔离、记忆协议或 UI 沙箱。普通文字不会被解析成真实操作；生成代码仍必须放在通过结构检查的 `ui` 通道。独立 UI 编排调用必须返回实际界面，不能用“稍后生成”的文字作为完成结果。

独立审查等结构化阶段也兼容完整的 JSON 围栏和二次编码，但仍执行原 Schema；自然语言“通过”不能变成 `supported=true`。MiMo 官方 Chat API 的 `tool_choice` 当前仅支持 `auto`，其他值由服务端移除，不能依赖 `required` 强迫返回工具；详见[官方接口说明](https://mimo.mi.com/static/docs/api/chat/openai-api.md)。

## 流式处理

`AnswerPreview` 按实际内容识别 JSON、围栏与 Markdown，只提取可见正文，不展示 JSON 内部字段或私有思考。`JSONEnvelopeStream` 按字符串和转义状态追踪单个根对象，剥离围栏后交给既有增量 UI 解码器。正文和 HTML 在后续分片尚未结束时就发送；不在生成完成后人为切片播放。

预览以独立 `reply_previews` 检查点保存，在每次 SSE 交付前落盘。刷新或断线后通过原会话 GET 恢复文字、CSS/HTML、已完整到达的本地脚本及修订序号；它不是已验证证据。新一轮改稿显式清除上一稿的界面与文字，正文重置与同稿 UI 保留分别控制。最终 Schema、引文、用户响应约束与独立事实复核通过后，才保存为完成回复、清除检查点并放开宿主动作。失败、取消、截断和引用错误不能通过格式适配变成已核验的历史。

## 阶段和耗时

已有原图随主调用发送时，界面显示“正在读取原图并分析内容”；工具之后的继续生成显示实际答复阶段，避免始终停在“确认问题与范围”。状态不展示隐藏推理，也不虚构百分比。

测试分别记录首段文字、首段 HTML、本地控件可用和最终复核完成。保留主 Agent 与独立审查的完整思考和配置输出上限；性能改进来自去除无效格式重写、减少无关记忆协议读取和提前显示真实内容，不以关闭事实审查换取表面速度。

只有附件全为可用图片、当前短请求明确查看/识别其内容，且没有研究、长期记忆、日程写入、交互界面或跨材料要求时，使用精简的图片阅读提示和单个最终答复工具。原图与稳定证据编号完整提供，不再给该任务附加文件、子任务与记忆工具目录。请求包含这些其他要求时保留完整 Agent 链路。独立审查仍使用同一原图和完整预算。工程记录同时保存 `focused_visual` 与格式规范化类型。

## 验证入口

- `python -m pytest -q tests/test_answer_format.py tests/test_agent_authoring.py tests/test_visual_evidence.py tests/test_openui.py`
- `python scripts/run_openui_browser_checks.py`
- `python scripts/verify_agent_adaptive_live.py --case timetable --allow-paid-synthetic-test --output-name answer-format-live`：付费、隔离合成课表，使用临时账号与数据库；不复制真实课表或写入正式会话。报告与实际首字时间在 `artifacts/answer-format-live/results.json`。

单次合成课表的完成结果不能代表所有图片、所有 UI 复杂度或固定响应时间。已经失败的历史消息保持原记录，用户可使用原重试入口重新处理。

纯礼貌表扬仅匹配有限的完整短句，无新附件、无界面提交、前文未要求确认时，可由宿主直接返回固定“谢谢！”，不访问模型或宣称业务完成。“可以”“好的”、疑问或带后续任务的消息仍走正常 Agent 与审查链。历史业务成功只能由本账号、本对话真实操作账本和本轮读取的当前状态支持；本轮没有调用工具不能推翻历史 committed 回执。
