## 修改边界

- `static/reference-interactions.js`：可中断的局部过渡、列表键盘行为、材料目录展开及现有代码按钮的反馈；不设置工作区宽度、字号、卡片网格或侧栏尺寸。
- `static/notice-compose.js`：将已有步骤切换接到局部过渡和完成标记。
- `static/workspace-search.js`：已有文件/筛选区展开；采用控件的目标状态处理快速反向点击。
- `static/genui/dom.js`、`static/genui/renderer.js`：两条已有代码渲染路径共用复制反馈，保留原有 Code 容器和唯一的复制入口。

过渡结束或因窗口变化、页面切换、减少动画偏好而中断时，临时动画被取消，原有自动布局立即接管。没有持久的内联像素高度。

## 验证方法

`python scripts/run_browser_checks.py` 使用 8786 上的独立合成数据，先执行现有稳定性和回归检查，再执行 `scripts/verify_reference_interactions.mjs`。它不会复用 8765 服务或正式账号。

新增验证针对快速连点、键盘选择、自然高度恢复、输入保留、缩放中断、减少动画、真实上传目录以及剪贴板成功/失败。测试结果只能证明这些边界内的行为；视觉是否符合使用者要求仍须结合实际页面判断，不以检查数量代替视觉评价。

相关文件：

- `static/workspace-search.js`：独立清除、条件标签、键盘选择文件、中文输入组合事件、取消过时请求、失败重试；文件解析结果继续复用。
- `static/workspace-tree-state.js`、`static/chat.js`、`static/sources.js`：对话材料及来源卡片的展开状态恢复，避免每次检索后重新整理。
- `static/chat-viewport.js`、`static/chrome.js`：在侧栏宽度变化的整个过渡期间维持可见文字位置；连续拖动复用当前文字锚点，用户主动滚动或操作阅读区时立即交还控制。
- `static/workflow.js`：保留面板和输入，记录滚动位置，第一个校验错误保持可见；`static/command-search.js` 让待办搜索结果直接打开对应办理窗口。
- `static/reference-interactions.js`：共用可中断过渡与原生详情状态，快速反向展开不残留不可操作状态。
- `static/workspace-layout.css`：新增条件标签样式；仅在可用高度不超过 560 像素时让表单事项信息和内容共用一个滚动区，保存区留在可见位置。主工作区、侧栏、字体和颜色不重排。

`scripts/verify_workspace_interactions.mjs` 使用真实组件、真实本地接口和合成记录，覆盖搜索清除与重试、旧响应、目录状态、菜单键盘、表单校验与保存、低高度窗口、聊天阅读位置。`scripts/run_browser_checks.py` 现在依次运行四组浏览器检查，GitHub Actions 上传全部报告、截图和日志。

上一轮云端 Chromium 检查暴露了测试同步问题：设置视口后，在 resize 事件尚未更新可用高度和侧栏宽度时就记录了基准。`verify_frontend_stability.mjs` 现在先等待实际视口高度及两帧布局，并同步待验侧栏宽度到其存储值；原来的填满容器、空搜索宽度不变和无水平溢出断言保留。
