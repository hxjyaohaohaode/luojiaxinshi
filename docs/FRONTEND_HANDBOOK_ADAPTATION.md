### 页面覆盖

- 工作台：森林绿主卡、原品牌角色、纸张层次、重点事项堆叠、滚动指标、七天期限条、办理旅程、完成圆环。切换重点卡仅更新卡片本身，避免整个页面重绘。
- 待办：按当前筛选结果分组；空列不占据整列视觉空间；一列时卡片并排，两列与三列按实际数据分配。切换视图不改动待办状态、办理记录或当前关键词。
- 通知资料：收件概览、卡片/列表、共享搜索与分页；卡片仍打开同一份原文。
- 提交通知：实时收件预览、材料检查项、拖放和粘贴、缩略图、连贯的步骤切换；草稿与附件校验延用既有保存机制。
- 对话：欢迎插画与轨道、场景卡、聚焦输入框、真实处理状态描边。
- 来源：官网、公众号、群的快速登记入口，仅预选平台，仍由本人填写并保存；既有来源仍通过可访问折叠卡展开。
- 记忆：通用/项目/专题与关键词组合筛选、实时数量、筛选空状态恢复。
- 原文和办理详情：阅读位置、材料勾选、时间线与弹窗过渡；数据和确认流程维持原有语义。
- 登录、注册、个人设置、日历：沿用对应任务布局，统一纸张层次、强调色、图标与焦点反馈。

### 运行与可访问约束

`static/experience-system.js` 与同名 CSS 统一入场、数字、圆环、指针、波纹、折叠、提示、离屏暂停；`static/task-views.js` 负责纯数据分组。CSS 没有内联样式字符串注入；动态坐标与尺寸通过 CSSOM 写入，保留既有 CSP。图片预览使用本地 data URL，不改服务器安全策略，不发送文件。

原生对话框、表单、链接、按钮与 details 继续承载交互；装饰层不拦截指针、不进入读屏树。后台、减少运动和用户关闭动效时暂停装饰并取消进行中的短动画。计数有稳定的辅助文本。Toast 的停留时长随正文长度调整，悬停、聚焦、后台时暂停；完成状态的撤回入口使用同一套计时与关闭机制，支持鼠标和键盘。

## 视觉与配重

- 主色继续采用珞珈绿 `#165c43`，主文字 `#20372e`，暖白表面 `#fffefb`，浅绿辅助区 `#edf2e5`。浅绿表面的小字使用更深的 `#5d7055`。
- 普通业务页面统一标题层级、内容左右边线、按钮、边框、图标和卡片间距。聊天和日历保留适合连续工作的紧凑工具栏。
- 工作台按“处理新通知 → 优先事项 → 总览 → 行动清单”组织视觉主次。提醒和流程提示放在辅助栏；窄屏按阅读顺序重排。
- 行动列表按可用容器宽度排版，宽屏按钮与标题并排，窄屏按钮进入独立操作行；标题保留完整换行。
- 来源卡片使用原生 `details/summary`，明确展开方向；办理弹窗保留固定标题和可滚动内容；账号页面的分组、卡片和使用偏好对齐。
- 现有品牌插画保持原图。新增入场与操作动效短暂执行；装饰轨道与浮动便笺在可见、前台且未打开模态时运行。所有新增动效遵循系统减少动态效果与浏览器内动效偏好。

## 交互与数据一致性

搜索支持 `/`、Ctrl/Cmd+K、方向键、Home/End、Enter 和 Esc；输入框中的 Home/End 保留文本编辑含义。查询优先匹配完整标题，其次标题开头、标题包含和材料/来源。每组先显示六项，可以继续展开。查询只持有本次弹窗自己的数据，不替换当前页面的数据集合。

文件队列在浏览器内显示真实选中文件；保存表单才上传。重复文件按名称、体积与修改时间判断。非法格式、超过大小或数量限制时，整个新增批次不加入。浏览器文件输入先发出的 `input` 不进入暂存；只有校验后的 `change` 才发布队列，避免非法文件名提前进入草稿。删除后恢复到相邻删除按钮或文件输入框，文件移除同步到草稿。页面刷新后提示重新选择本地附件；明确放弃缺失附件会写回草稿。退出登录清理内存中的附件对象。

步骤条只导航已有提交阶段。材料概览显示标题、正文和附件的当前输入情况，不把“已填写”当成材料已经齐全。后台处理指示根据服务实际阶段更新，不把未知阶段当作已开始，不标记推断的上一步完成。

## 验证方式

使用 `scripts/mvp_preview_server.py` 启动隔离的合成数据服务（默认 `127.0.0.1:8780`）。数据目录必须位于 `artifacts/`，脚本不读取正式 `data/`，不配置模型密钥。重复执行大量注册场景前重新启动该测试服务；服务保留正式限流规则，不修改生产认证逻辑。

PowerShell 示例，在仓库根目录执行，Playwright 已安装时：

```powershell
$env:MVP_ARTIFACT_DIR = 'artifacts/handbook-upgrade'
$env:MVP_BROWSERS = 'chromium,firefox,webkit'
node --test tests/*.test.mjs
node scripts/verify_mvp_browser.mjs
node scripts/verify_handbook_frontend.mjs
node scripts/verify_handbook_visual.mjs
node scripts/verify_upgrade_interactions.mjs
node scripts/verify_draft_continuity.mjs
```

`PLAYWRIGHT_PATH` 可指向已有 Playwright 安装，无须加入应用依赖。导航焦点回归使用现有 `verify_navigation_focus.mjs`，本轮覆盖菜单键盘返回、Esc 弹窗层级和延迟聚焦不抢占输入三组场景。结果及边界见仓库 [验证记录](../TESTING.md)。

第一轮验收在 `artifacts/frontend-handbook/`；深度融合的验收图片和 JSON 在 `artifacts/handbook-upgrade/`，作为本地工程证据，已被 Git 忽略。粘贴测试使用合成剪贴板事件；移动尺寸和三种浏览器引擎测试不等同于手机硬件、系统软键盘、系统剪贴板或真实用户体验验收。
