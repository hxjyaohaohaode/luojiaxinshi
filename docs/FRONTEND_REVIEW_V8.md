# 界面与交互验收 v8

应用版本 1.18.0。以实际体验的 20 条浏览器批注为验收条件，覆盖布局、编辑空间、异步反馈、依据导航、临时分支和交互编排耗时。

## 布局与文案约定

`static/workspace-layout.css` 统一管理视口和工作区域：外层拥有可视高度，内部通过 flex/grid 的剩余空间分配尺寸，滚动留在实际阅读或编辑区域。聊天、知识树和侧栏不再各自猜测内容高度。改变窗口大小、折叠侧栏、切换窄屏、打开详情或可视高度缩小时，工作区重新分配空间。按钮和输入框保留可用的操作尺寸。

删除重复的页面标题、介绍、宣传语和空详情说明。工作台、通知资料、通知表单、来源、待办、记忆和登录都按此约定清理。实际记录标题、字段标签、真实状态、输入限制和错误信息继续作为操作信息展示。

## 编排速度与事实核验

规划器增加 `presentation`：`text`、`compact`、`interactive`、`auto`。简单确认、资料缺失或明确要求文字时可选择文字；普通日程、清单、时间线可选精简协议；需要图表、试算或联动时保留自定义交互。实际能力受部署支持的层级限制，使用选择不交给用户配置。

已准备证据的 UI 编排关闭第二轮长推理；需要同时完成覆盖分析的文字生成继续推理，独立事实和 UI 核验继续运行。未通过的稿件不能作为已核验结果发布。核验通过后的传输从每次 240 字符调整为 8192 字符，减少重复保存与页面更新；Unicode 与中断持久化检查继续生效。遥测读取实际请求的推理模式。

真实接口工程样例只提交两条合成安排，不读取应用账号、通知、会话或日程数据库。最新一次小样的首段文字预览为 **1.538 秒**，界面编排 **4.902 秒**，包含独立核验 **17.919 秒**；生成 1 个 UI 块，独立核验无问题。共 2 次真实模型调用。此测量不包含检索规划、资料检索或完整业务问答，不用于推断复杂任务的耗时或事实准确率。
