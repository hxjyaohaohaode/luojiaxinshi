# 1.19.0：工作区稳定性与语音复用

记忆工作区明确占满父容器，管理操作进入完整模态窗口；聊天来源面板只调整现有容器，朗读结果在页面内及服务端复用。本轮对应五条实际浏览器反馈。

| 反馈 | 最终行为 | 主要实现 |
| --- | --- | --- |
| 记忆宽度随内容变化 | 清除旧的 1500px 上限和自动外边距，设置完整宽度；搜索空结果、侧栏宽度变化、窗口缩放保持填满父容器 | `static/workspace-layout.css` |
| 设置浮层难用 | 单一原生 dialog，按自动维护、使用与保留、导入导出分组；保留项目、整理、生命周期、会话、历史和文件操作；关闭返回真实触发按钮 | `static/memory-tree.js`、`static/memory-studio.js`、`static/app.js` |
| 展开来源时聊天不稳 | 保留消息、编辑器、输入草稿及音频 DOM；原字号随容器换行，通过可见文字锚点或阅读底部保持位置；来源列表更新保留面板 | `static/chat-viewport.js`、`static/genui/citations.js`、`static/chat.js` |

| 朗读重复生成、控制拥挤 | 单行播放、进度、时间与关闭控件；暂停、继续、关闭后重开复用音频；读完可重放完整回答，长回答依序分段 | `static/reply-speech.js`、`static/speech-text.js`、`app/speech_cache.py` |

服务端缓存按账号、回复、精确正文、模型、音色、指令和凭证配置区分；相同在途请求共享一次合成。缓存命中仍校验登录、CSRF、外部处理同意及回复归属。回复、对话、账号删除会级联删除相应缓存；生成期间删除来源不会重新写回缓存。失败不缓存、不自动重试，缓存写入失败仍返回已生成音频。缓存保留七天，每账号有效音频最多 64 MiB，全局有效音频最多 256 MiB。SQLite 文件可保留已释放页面，因此上述限制针对存活缓存内容。声音复刻录音不进入持久缓存。

页面缓存有 40 MiB 上限，退出账号清理；停止播放释放对象 URL，但保留可复用的 Blob。修改回复内容或音色后使用新缓存键。播放器只在用户要求朗读时出现。

日期和时间转为适合朗读的中文表达，去掉引用编号、链接地址、代码块和表格分隔线，分段保留完整正文和 Unicode 字符。使用现有 MiMo 音色与明确的自然朗读指令，没有接入新的处理商。

本轮实际重新检查了用户提供的 `D:/项目文件/frontend-component-handbook.md` 中 SmoothUI Dialog 的实现 `SRC-917ADE486E20E7`，包括同一弹窗的打开状态、触发器、标题、关闭子件与减少动效机制。本项目继续采用现有原生 dialog，适配其交互结构。参考中的 React/Base UI 组件没有直接复制为本项目依赖。此前参考的侧栏 Header/Content/Footer 与容器填充约束继续保留。
