## 已取得的内容

`public-notice-candidates.json` 记录 17 个武汉大学官方来源：申请／报名 8 个、材料报送 3 个、活动 6 个。保存原始 URL、标题、页面发布日期（可核实时）、事项分组和后续核对重点。只收录已通过官方检索或正文阅读确认的地址，排除了人员名单公示、身份认证页和单纯搜索列表。

这是 AI 辅助的来源筛选记录。其正文快照、附件完整性和独立人工标注尚未齐备，因此 `split` 均为空、`eligible_for_frozen_evaluation` 均为 `false`。17 个来源不能计为原方案要求的 10 个开发样本和 20 个独立测试样本。

同一事项的补充、更正、不同语言或重复转载须使用同一个 `family_id`，不能跨开发集与测试集；当前分组仍需在取得完整材料后复查。样本不能因为模型表现不好被删掉或移回开发集。

2026-10-18 18:26（北京时间），本机对 7 个已发现的来源域名各取一个候选进行只读 HTTP 探测：5 个返回 403；边界与海洋研究院站点报告 TLS 域名不匹配；知识产权信息服务中心连接提前断开。保留证书验证、无自动重试，没有把错误页面保存成通知正文。机器报告：`artifacts/mvp-acceptance/public-source-access-1.12.0.json`。

正常 Edge 浏览器成功显示并通过 DOM 读取了[2026 年上半年研究生毕业须知](https://journal.whu.edu.cn/graduate/notice/20251218qgky)正文和五条附件链接。最初自动可访问性读取超时，改用已支持的 DOM 接口取得正文；因此本机 HTTP 探测失败不等于该网页对所有访问方式不可用。

五份附件下载操作未在工具观察时间内返回可核验的本地路径，结果标为未知，没有重新下载或假定成功。该页只计为已观察正文与附件链接，尚不是正文和附件齐全的归档样本。其他候选以检索结果或官方正文阅读为来源入口，不声称已经完整下载。

## 已发现的真实业务边界

这些是后续开发检查点，不是人工标准答案或模型得分：

- [2026 年转学院通知](https://journal.whu.edu.cn/20260106emgc)：网页发布日期与落款日期不同；学生申请、学院审批、第一轮失败后的第二轮资格应分别处理。不能将学院处理日作为学生提交截止。
- [2026 年研究生毕业须知](https://journal.whu.edu.cn/graduate/notice/20251218qgky)：博士和硕士有不同的预答辩、资格审查及论文提交要求；附件混有 DOC、DOCX、ZIP。原 MVP 的格式限制和关键材料缺失提示必须真实生效。
- [2025 届测绘学院毕业论文答辩通知](https://www.sgg.whu.edu.cn/info/1380/40861.htm)：学生定稿、导师审核、秘书归档及首次／补答辩是不同分支，网页列出六份附件。不能静默丢掉超出上传上限的材料后宣称材料齐全。
- [2026 年试验班二次选拔](https://journal.whu.edu.cn/undergraduate/notice/20260828hd85)：纸质与电子材料同时收到才满足报名要求，报名与面试分别计时。
- [研究生学术创新奖评选细则](https://journal.whu.edu.cn/202607205014)：常设资格和评选流程不等于已发布本年度申请截止时间。

## 形成可计分样本前需要完成

1. 取得完整通知原件及其实际需要的附件；记录来源、取得时间、文件哈希和缺失情况。涉及敏感名单的内容不作为普通公开样本复制。
2. 明确具体使用者的条件。测试画像可以合成，但必须标注为合成，不能等同于真实学生。
3. 人工核对八类事实及个人行动：主题、适用对象、时间、行动、材料、提交方式、地点、联系人；逐项记录原文依据、责任主体、必办／可选／核实、条件、先后关系和未知值。
4. 区分模型遗漏、错误新增、错误责任人、错误期限、输入不支持、请求失败及人工回退。失败不能从统计分母消失；人工处理时间还需包含准备、等待、核对与日历操作。
5. 按事项分组划分至少 10 个开发样本和 20 个独立测试样本，先冻结来源、人工标准答案、评分规则与版本，再运行测试。测试集不用于调整提示词或筛选“成功样本”。

用户已明确答复现有真实通知原件与人工标准答案“目前暂无”。不能继续把这一状态写成尚未回复，也不能将 17 个候选入口或 AI 生成的答案当作独立人工标注。原方案的五位真实参与者、三条件对照、五个实际使用日和真机提醒要求仍独立保留；此目录不将它们计为通过。
