# 安全边界

## 可执行内容边界

模型只能描述 catalog 中的属性和事件。渲染模块只构建固定 DOM/SVG/MathML 标签并赋 textContent，不接受 HTML、CSS、任意属性名、事件函数、脚本或外部脚本。无 eval、new Function、innerHTML、srcdoc、动态脚本标签或任意 HTML 沙箱。独立 Markdown 子集将原始 HTML 当文字显示；远程图片默认拒绝。链接只接受 http/https/mailto，打开新页附 noopener/noreferrer；按钮外链另受固定域名白名单限制。

输入树逐层拒绝 __proto__、constructor、prototype。JS 状态与属性克隆使用无原型对象；节点和表达式缓存用 Map；读取状态只接受自身属性和有界路径。组件名称查找也检查自身键，避免利用对象继承链冒充组件。

表达式独立解析为受限 AST，只有目录中的纯函数；没有赋值、数组属性访问语法、循环、用户函数或全局对象。限制字符串、深度、解析步骤和求值步骤，非有限数值降级。图表 SVG 属性由本地数值代码产生，不接纳模型样式。

## 动作与数据边界

只有 state、open_url、host、ask_model。change 事件只允许本地 state；其他动作必须来自点击或表单提交。host 名称与参数使用目录白名单；高风险注册项必须调用宿主确认器，缺少确认器则不执行。当前只注册导航、材料查看及本地导出，不含提交学校表单或修改真实待办的动作。

上传材料、模型正文中的 data 操作和任意 origin/server 声明不授予信任。可信 data 由服务端独立传输；当前仅提供用户已加入本次对话的材料索引，不额外上传私人日历或通讯录。表格 CSV 导出在可能触发电子表格公式的单元格前加文本前缀。

## 服务与持久化

原有登录、所有权、CSRF、Origin、配额、会话版本和重试校验共同应用到新通道。每个流在发送增量前写本地检查点；取消令牌胜过迟到结果。保存互动态独立 CAS，用户无法给其他人的消息写状态。快照端点请求体上限 256KB，内容上限 128KB；模型单条/单块/节点/字符串和计算限制来自统一目录，可通过 GENUI_LIMITS_JSON 收紧。

新表均用外键关联原会话/用户，删除原会话时不会留下孤立互动数据。没有第三方遥测、分析请求或新增模型服务；API 密钥仍只存在服务端现有配置。正常日志不记录消息、材料、快照、个人资料或凭证。开发原文查看仅在本机开发开关开启时提供；原文本身始终受会话所有权保护。

## 仍需注意

最终引用检查只能证明引用确实存在于材料，不保证模型结论正确。流式文字在最终校验前属于临时输出；失败、取消及未配置模型都有显式状态。用户材料中的误导性指令即使影响了模型，也不能扩大渲染器或动作的权限。

公众部署时，运营方需要自行评估 AI 生成内容标识、个人信息告知与同意、数据保存期限与删除机制、模型服务的数据处理范围以及学校标识的使用方式。本文件说明工程边界，不作法律结论。

## 媒体、表格与共享仓库

Video 只接受宿主确认的同源私有资源；按需请求，禁止自动播放和外部 iframe。后端验证文件类型、大小、所有权及 Range 范围，错误范围返回 416。视频内容不加入模型输入。Plot 使用既有受限表达式，不接受脚本、CSS 或全局对象。

XLSX 禁止宏、外部工作簿和加密内容，限制压缩包数量与解压体积；最多 20 个工作表、每表 1000 行、50 列、总计 5000 个单元格及既有文字上限。公式仅显示文件中缓存值，不重新计算。导入包限制大小、深度、字段与所有权，使用预览摘要确认并幂等追加；导入期限必须再次核实，提醒不会自动启用。

语音请求使用现有 MiMo 服务通道，需要用户明确操作与相应确认；音频处理方式及授权要求见 MIMO_INTEGRATION.md，不把云端 ASR 宣称为纯本机识别。

公开 Git 仓库排除 .env、私钥、数据库、备份、真实账号导出、日志及验收会话。随仓库提供的项目方案与设计资源不含用户的业务附件；界面资产本地化。上传前扫描当前候选文件和所有历史对象，检查敏感路径、常见凭证格式及文件体积。扫描属于工程防线，不保证识别所有可能的敏感内容。
