新增 GenUI 目录的 JS / CSS 合计 188341 字节，逐文件 gzip 估算合计 55960 字节，包含开发画廊、夹具和 E2E 工具，不等于生产页面一次下载量。图表和函数绘图由按需导入的图表模块承载；演示视频为额外 100020 字节、按需加载。精确清单见 `verification/module-sizes.json`，gzip 估算不冒充实际服务器压缩量。

### 产品界面实际操作

- 日历折叠侧栏后可以立即重新打开；全高分隔线到达底部，指针可从底部拖宽，方向键 / Home / End 可在约束内调宽。桌面最大测试 460px，导航文本和 AI 标记没有重叠。
- 1651×871 日历日视图完整时间轴无额外纵向卷动；390×844 移动周课表完整显示 14 节。向下阅读隐藏导航、向上恢复，停留 1.8 秒恢复。不存在页面横向溢出。
- 320px 对话编辑区约 53.3px；Shift+Enter 插入换行，Enter 实际发送并保存合成 SSE 回复。去掉用户气泡的重复称呼，状态与时间来自实际消息流程。
- CSV 上传、按附件正文检索、分页表格预览、转通知、手动草稿排序、确认一个步骤、待办中展开/收起预览、带材料回到对话均逐步操作通过。通知编辑器曾在 320px 溢出，修复后重新验收。
- 来源卡片折叠、列表分页、个人偏好设置、单一菜单入口、窄屏输入和长文字状态已检查；生产设置不暴露密钥填写入口。
- Codex 自带批注的本机 CSP 兼容由专门的 2 项测试覆盖，且用户已经确认可以正常批注。生产 CSP 未放宽为任意内联样式。

### 复现与证据

在仓库根目录运行 CONTRIBUTING.md 中的测试命令。画廊 `/static/genui/gallery.html` 的“运行组件验证”覆盖组件与性能；`scripts/genui_test_server.py` 启动 8767 隔离服务，测试账号 `browser_test` / `UI-Test-Only-2026` 只用于合成数据。画廊中的端到端入口仅用于该隔离服务。`scripts/verify_local_runtime.py` 自行创建临时数据库并启停测试进程。

共享证据位于 `verification/`：桌面与暗色窄屏画廊、6 项端到端、40 条离线领域评测、并发/重启/恢复、依赖审计及模块大小 JSON。消息正文、登录会话、管理员链接及本机数据库没有共享。

### 未验证与限制

真实 MiMo 回复的质量与 GenUI 自主选择、真实语音识别和播报、实体手机、真实学校系统/渠道授权、外部日历提醒、生产服务器和容器构建均 **未验证**。附件展示是有明确边界的预览：PDF / DOCX 使用提取文字，CSV / XLSX 不保留原始版式和公式重算；不支持扫描件 OCR、任意网页视频嵌入或自由 HTML 小工具。应用并未内置通用联网搜索工具，不能声称模型已实时搜索。

GitHub CI 需在上传后查看实际运行结果；本机全套通过不预先等同于云端检查通过。

### 干净发布包复验

从源码发布 ZIP 解压到新的隔离目录，使用已有锁定 Python 环境但不复制任何 .env、数据库或会话：初始化成功，1.2.0 健康检查成功，10 个运行时图片/图标/视频逐个返回正确字节长度，并在解压后的源码上重跑 150 项 Python 测试全部通过。此项没有在新电脑重新下载依赖，不能替代全新系统的安装与网络验证。结果见 `verification/release-smoke.json`。
