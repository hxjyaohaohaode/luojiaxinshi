# 生成式界面设计与决策日志

## 目标与边界

文字优先。模型只描述内容与组合，不生成或执行 HTML、JavaScript、CSS。独立实现框架无关核心，原生 DOM 渲染，共用组件目录。新的生成式区域沿用珞珈绿、4/8 间距、语义状态和减少动效设置；支持区域亮暗主题，不改变既有业务审批语义。

## 分层

1. `schema/genui/catalog.json` 是唯一人工维护的组件、属性、默认值、动作与上限目录；脚本生成浏览器模块及紧凑能力说明。后端直接读取同一目录。
2. 核心库负责 UTF-8 增量解码、围栏与 JSON 行解析、逐节点校验、受限表达式、状态和扁平图规范化。
3. 渲染器只用 createElement、textContent、显式属性和确定性 SVG。根据 id 复用节点，requestAnimationFrame 合并更新，单节点隔离异常。
4. 新 SSE POST 通道转发 answer 的文本增量；取消、超时和中断保留已经收到的文本。旧 POST 及 JSON 回复在关闭开关时维持原流程。
5. 服务端最终校验 raw/spec/parts，并在附加表中保存；用户显式保存的互动态采用独立版本号，防止跨标签页覆盖。

## 决策日志

| 决策 | 理由 |
| --- | --- |
| 原生 JS/Python，共享 JSON 目录 | 现有项目没有前端框架，避免引入大依赖及许可证、构建与升级负担 |
| 新通道使用 fetch POST + SSE | 可携带现有 CSRF 头和 JSON 提交体；旧接口不变；不需要 WebSocket 服务 |
| 支持 JSON 的模型保留 JSON 外壳、增量解码 answer | 保留原来的 citations 校验与安全人设；让普通文字先到达前端 |
| 不支持 JSON 的模型降到 Tier 3 文本 | 不伪造引用能力；保留材料与人工核对入口 |
| 独立功能总开关与个人设置 | 部署管理员可以整体禁用，用户可以切回原有文字模式 |
| 附加表，不改基础 schema 4 | 旧程序忽略新表即可运行，代码回退不删除消息、快照或用户数据 |
| 输入交互无网络，保存互动进度单独点击 | 满足本地实时计算，也避免滑动、排序导致请求或费用 |
| data 只信任独立服务端注入 | 模型输出的 origin/server 标记不授予信任；原始 data 操作不能伪造工具结果 |
| 外链与图片分别白名单 | 外链由用户点击打开；远程图片默认关闭，同源图片须出现在宿主提供的资源列表 |
| 领域宿主只注册固定入口和预览 | 不允许模型直接写待办、调用任意函数或冒充办理完成 |
| HTML 沙箱保持关闭，不实现任意代码执行 | P2 可选项不应扩大当前 MVP 的攻击面；HostView 使用类型化本地组件 |
| Map 不注册 | 项目没有已有地图服务，避免新增第三方请求和数据传输 |
| 公式采用文本/MathML 的安全子集 | 不引入 TeX 执行或第三方脚本，复杂公式保持可读文字 |
| 无实时密钥的评测使用明确合成夹具 | 检查协议、安全与交互，不把夹具通过率称作真实模型效果 |
| 总渲染条目上限 5000 | 防止同一份大数据被多个节点反复引用导致 DOM 放大；超出的节点局部降级 |

## 交互原则

主回复中只显示与问题有关的组件。布局最大 4 列，320px 自动收敛；长表格分页、图表可切表格；密集细节进入折叠区或标签页。数字使用等宽数字，操作目标 44px，焦点可见。上滑阅读时不自动追到底部；可主动跳到最新。所有交互状态仅是本次回答的状态，不代表学校办理结果或真实待办状态。

## 分阶段交付

Phase 0 审计 → Phase 1 目录与协议 → Phase 2 核心与安全测试 → Phase 3 组件/画廊 → Phase 4 传输/存储 → Phase 5 提示词/分层评测 → Phase 6 对话集成 → Phase 7 回归/性能/交付。每阶段本地提交，不推送。

## Phase 6 集成补充

消息气泡使用按消息 ID 保留的 DOM 渲染器，用户和模型正文均通过 textContent / 安全 Markdown 处理；仅宿主静态模板仍使用既有 HTML 模板方式。模型内容不进入 HTML 插入接口。

按问题选择结构的指令已独立加入能力模块：结论先行、计算结果与参数分区、计划的行动与依据分层、对比按维度选择卡片或表格、多主题使用标签、次要细节折叠。四组组合场景放在画廊“按问题组合”中；这些是明确标识的工程示例，不能作为模型智能水平的证明。Tier 1 不受模板种类限制，可组合整个组件目录；Tier 2 才使用模板约束。

用户要求继续压缩输入区域后，采用单行起始、随输入自动增高的编辑器（44 至 144px，并受屏高约束），按钮保持44px；桌面顶栏56px，移动52px。把状态和材料数量保留在无障碍状态区域，原材料入口仍可随时查看。长清单先显示6项，展开状态可保存。

HostView 注册 campus_schedule、material_index、messenger；前两项从当前账户的宿主数据读取，模型不能伪造待办完成或材料内容；小信使只使用项目本地原创图片。没有注册任何写待办、发消息或校内办理动作。

实际数据保存采用显式“保存互动进度”，避免本地拖动、排序、切换标签触发网络；有冲突时提示刷新核对，不覆盖其他页面的版本。表单提交以可读摘要展示在用户气泡内，模型收到的仍是有明确“数据而非指令”声明的结构化事件。
