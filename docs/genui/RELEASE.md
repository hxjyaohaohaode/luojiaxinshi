# 运行、交付与回滚

## 运行

本次交付版本为 1.2.0。克隆仓库后按根目录 CONTRIBUTING.md 启动；首次启动会创建本机独立数据和空密钥配置。生产服务器部署步骤沿用 OPERATIONS.md。项目附件清单在 `项目资料/文件清单.json`，运行时资产全部在 `static/assets/`。

生产部署需要管理员配置 HTTPS、模型凭证、备份和运行监控。用于工程验收的 8767 服务只产生合成输出，不能作为已接通真实 AI 的证明，也不应用作公开生产实例。

## 功能回退

1. 在本机配置中设置 `GENUI_ENABLED=false` 并重启。新消息恢复文字接口；旧消息仍可读取和复制，不删除原文或用户资料。
2. 个人“互动回答”设置也可以关闭当前账号的组件展示。管理员总开关优先。
3. 需要退回旧代码时，先停服务并使用 `manage.py backup` 生成备份。在另外的干净检出目录部署已验收提交，保留数据副本；不要执行 `git reset --hard` 或删除附加表。

GenUI 消息、状态、传输记录和导入回执采用增量附加结构。旧代码可以忽略新表，但不会提供新增功能；导入回执与媒体扩展不应被旧程序重写。恢复工具只接受新的空数据目录，恢复后会撤销旧会话和邀请。涉及跨版本回退时先在备份副本演练，不能直接操作唯一真实数据库。

## 共享内容和排除内容

包含：应用代码、锁定依赖、启动脚本、原生前端、生成式组件目录/协议/夹具、测试与文档、原创角色/图标/视频、项目方案与调研附件的定稿，以及固定版本的 CI 检查。

排除：`.env`、数据库、账号和聊天、真实用户上传的附件、管理员邀请链接、私钥、日志、备份、本机依赖环境和有用户数据的验收工作目录。1.20.0 起仓库不再保存逐轮验证 JSON，测试结果以对应提交的 CI 运行记录为准，此前的合成测试统计见 git 历史。历史提交也在上传前检查敏感路径和常见凭证格式。

本次没有修改用户提供的 Word/PDF 原件；资料副本以 SHA-256 核对。第三方参考图片不是运行依赖，未随仓库再分发。源码发布包由 `python scripts/build_release.py` 生成，显式白名单收集文件并输出校验和。

## 尚需实际环境验证

真实模型的布局取舍、内容准确率、调用费用和延迟；真实麦克风及播报体验；Android / iOS / HarmonyOS 实机与软键盘；外部日历锁屏提醒；QQ/公众号授权接口；生产反向代理、容器镜像构建及目标服务器容量。浏览器模拟尺寸、合成服务和本机测试不能替代这些验证。

1.20.0 已加入隐私政策与用户协议的按版本同意、注销账号、自动备份按期轮换和 AI 生成内容的显式与隐式标识，说明见根目录 README 的“隐私与 AI 标识”。面向公众前，仍由项目方自行评估这些实现是否满足适用规定，以及个人信息处理范围、校园标识使用及项目/素材许可证。这里记录待评估事项，不给出法律结论。
