## 本轮修复

1. 模型生成的按钮提示和选项不能重新授予用户已禁止的私有资料访问权限；只有实际用户文字或服务器确认的已编辑自由文本才能改变范围。
2. 聊天首次发送确认本对话模型授权；取消保留草稿，授权可撤回，撤回会停止当前回复并阻止旧请求重新授予授权。
3. 当前轮的句数和界面要求在自动修正中继续生效。稳定证据标记由服务器转换为显示编号；独立复核接收明确的从 1 开始的映射。
4. 整条回复可登记最多 120 处真实引文，与服务器证据索引一致；不再因超过 24 处引文而拒绝合法长回答，每项引文仍逐字核对。
5. 原生界面图与状态转换的编排开启思考；准备好证据后的纯文字展示关闭思考。阶段摘要继续由 Flash 处理受约束的实际工作事件，不展示内部推理。
6. 覆盖检查和独立复核接收同一上传原图。图片定位说明明确为视觉观察，不能冒充 OCR 原文或逐字引文。
7. 公共网页读取不再局限于机构后缀；实际连接固定在已检查的公共 IP，拒绝私有地址、混合 DNS、越界端口和不安全重定向。
8. 动作内的嵌套表达式也在发布前校验，前后端采用同一语法；本地布尔值不能冒充持久保存，实际保存使用宿主功能。
9. 分支重建附件地址与资源引用，保留原始逐字引文和无关的字面 ID；删除原对话后分支原件仍可读取。
10. 备份与恢复清除回复分享令牌及对话模型授权，避免旧快照恢复已撤销授权。额度检查在取消旧任务前进行，拒绝新补充时继续保留原任务。
11. 多阶段默认总时限改为 1,800 秒；单次 HTTP 闲置等待仍为 180 秒。复核保留完整相关原文，只去掉同一引文在请求中的重复副本，不缩减事实审查。
12. 源码包包含资源来源 JSON 与素材构建脚本；Docker 构建上下文进一步排除环境密钥、数据库、日志及本地发布包。
13. 覆盖检查采用已配置的输出预算；规划等较小阶段遇到明确的长度截断时，最多扩展至该配置上限重试一次。不会接受半份审查，不重跑已完成的检索，不对凭证错误重试，也不无限增加调用。
14. 作者可内联完整子节点，服务器在相同节点、深度和动作限制下编译为传输图；保留旧 ID 引用格式。两种形式均经过流式解码、逐字引用、状态与非法输入回归。
15. 宿主交互协议明确区分自动附带的已编辑选择与按钮额外 values，避免审查员把实际已传递的批注误判为遗漏；服务器仍验证字段、所属记录、大小和来源。
16. 联网检索的“当前日期”统一使用北京时间，覆盖 UTC 与北京时间跨日时的差异；抓取时间戳仍保留实际时区。
17. 工作区原文按钮可打开本回答已核验证据中的准确 URL，避免非武大官网的合法来源被旧域名限制误拦；仍拒绝换路径、加参数、仿冒域名、凭证 URL 和脚本协议。
18. 来源预览优先显示实际登记的正文引文，点击某个编号则显示那一处准确原句，避免显示站点导航或 CMS 页脚。
19. 句数检查识别用逗号、分号接续主句的逐字引语，保留其中原始句号；独立引文、多句全文加引号、未闭合引号和真正多句仍按原约束拦截。修正反馈明确引句的接续方式，不截断或改写用户原句。
20. 界面提交气泡显示用户实际填写的问题；经过服务器验证的全部选择仍可展开核对，内部状态 JSON 和枚举值不再直接铺在气泡里。原始证据不删改。
21. 来源侧栏开合在界面重排后保持引用阅读位置，长引文编号可换行；正文中段实测开合偏移小于 0.1 像素，滚动底部受最大滚动范围约束时仍保持引用可见。
22. 首次容器 CI 的本地模式配置被启动器正确拒绝（容器需监听内部非回环地址）；验收改用与部署一致的 production 配置、占位 HTTPS 源和准确 Host 请求头，保留本地监听保护，并在失败时保留容器诊断。内部 HTTP 检查不冒充公网 TLS 验收。
23. 英文 Windows 的重定向输出可能使用 cp1252，原恢复命令在完成数据库恢复后输出中文时返回编码错误；操作命令统一输出 UTF-8，离线评估与业务验收工具采用相同约定。以强制 ASCII/cp1252 子进程及实际恢复验证结果，保留窄编码失败记录。
