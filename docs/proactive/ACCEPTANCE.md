## 产品目标与边界

学校暂无数据接口。基于可公开读取的官网、具备实际接入条件的公众号、授权群消息与本人上传资料，为不同身份提供个性化的信息发现、证据核对、持续追踪、办理路径和可靠提醒。用户决定是否加入个人待办；系统自动跟踪信息，不能要求用户逐条选择是否跟踪、手工清理过期机会或修正系统自行捏造的日期。

主链路：发现 → 正文/附件 → 来源与版本 → 关联补充和反证 → 适用性/兴趣/重要性/时效分别判断 → 个性化呈现和推送 → 用户选择加入待办 → 办理与反馈 → 依据变化后重新核对。不能以生成草稿冒充正式提交，不能以推送供应商受理冒充用户已读。
