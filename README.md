# 珞珈信使

本地优先的校园通知与行动助手（1.2.0）。围绕师生自己的材料开展连续对话，把校园通知整理为可回查依据、经本人确认的待办，并使用日历安排课程和个人事项。

**同学第一次拉取请先看 [协作开发指南](CONTRIBUTING.md)**。项目方案、接口调研、核验底稿和原创视觉稿已包含在 [项目资料](项目资料/README.md)；所有运行时图片、图标和视频均在仓库内。当前功能与未验证事项见 [最新验收记录](docs/genui/TESTING.md)。

## 现在开始使用

1. 双击本目录的 **`启动工作台.cmd`**。服务在后台运行，浏览器自动打开。
2. 普通成员可在登录页直接创建账号，选择自定义账号名、学号、工号或手机号，自行设置至少 12 个字符的密码。首次管理员仍通过本机一次性邀请建立，不向公开注册账号自动授予管理权限。
3. 保存注册时显示的一次性恢复码；忘记密码可凭它重设。进入“和小信使聊聊”，上传通知、截图或附件，补充问题；在“个人与账号”填写对判断有用的校园条件。

固定访问地址：<http://127.0.0.1:8765>。管理员首次注册链接也保存在 `data/admin-setup.url.txt`。注册后使用自己的账号登录；维护者可通过本机命令管理邀请，普通用户界面不提供成员邀请入口。学号、工号和手机号只是自填账号名，不代表学校或短信验证；微信与 QQ 联系号可在个人资料中登记，平台授权另行管理。

关闭浏览器不会停止服务。需要停止时双击 `停止工作台.cmd`，修改配置后双击 `重启工作台.cmd`。重启电脑后再运行启动入口。重复启动会复用本目录的已运行服务，不会重新覆盖数据库。

本机模式监听回环地址，只在这台电脑上访问。之后部署服务器时沿用同一应用和数据结构，见 [OPERATIONS.md](OPERATIONS.md)。

页面按电脑、平板和手机的浏览器宽度自适应，支持鼠标、触屏和键盘操作。无需给每个硬件型号分别安装客户端。当前提供 Windows 本机启动入口；部署到服务器后，其他设备通过 HTTPS 地址登录同一工作台。响应式验收尺寸及尚待真机验证的系统见 [TESTING.md](TESTING.md)。

## 配置小米 MiMo

项目的全部模型调用统一使用小米 MiMo。编辑本目录 **`.env`**，填写 `MIMO_API_KEY` 后重启，其余五个模型已预置：

```dotenv
MIMO_API_KEY=在本机填写小米按量 API 密钥
MIMO_BASE_URL=https://api.xiaomimimo.com/v1
MIMO_TEXT_MODEL=mimo-v2.6-pro
MIMO_ASR_MODEL=mimo-v2.5-asr
MIMO_TTS_MODEL=mimo-v2.5-tts
MIMO_VOICE_DESIGN_MODEL=mimo-v2.5-tts-voicedesign
MIMO_VOICE_CLONE_MODEL=mimo-v2.5-tts-voiceclone
MIMO_TTS_VOICE=mimo_default
```

主模型负责多轮问答、截图理解、结构化提取和互动回答。语音输入使用 MiMo ASR；“个人设置 → 语音播报”提供普通播报、音色设计和授权声音复刻。全部请求经服务端发送到小米，密钥不进入浏览器。旧的 `AI_API_KEY`、`AI_BASE_URL`、`AI_MODEL` 已停用，不会回退到其他供应商。

本项目目前对接小米按量 API；Token Plan 专用密钥、端点及其用途限制不能与按量 API 混用。填写配置仅表示准备就绪，真实连通性、权限、费用与质量须在提供密钥后逐模型验证。详细能力、接口、语音上限和验收步骤见 [MIMO_INTEGRATION.md](MIMO_INTEGRATION.md)。

未填写 API 时，会话、问题、材料仍能保存；通知保存、附件解析、手工整理、确认待办、修改记录、日历导出均可使用。配置模型后可重试之前的问题，继续同一段对话。图片由视觉模型读取，重要内容须本人核实。AI 按每次通知单独确认外部处理；成功结果仍是草稿，不会自动成为正式待办。

## 从材料开始连续对话

在对话中添加文字、PDF、DOCX、TXT / Markdown、CSV / XLSX、图片或 MP4 / WebM 视频，可以反复补充材料和追问。每次会话独立保存材料、消息与回答依据，支持历史检索、改名、删除、停止生成与失败重试。模型只接收本会话内容及必要个人条件；自填联系方式、学号、工号与登录密码不加入个人条件上下文。

需要办理时选择“转为通知”，仅复制选中的原始材料到通知核对流程。对话回答不会直接变成正式通知或待办；个人课表、简历等参考材料可以不转入。通知保存独立副本，删除对话不同时删除通知副本。

“我的通知来源”可登记官网、公众号、群与校内平台的名称、用途、学期。QQ 机器人单聊收件和获授权发布账号文章导入已有可配置适配器；凭证为空时显示未配置。接入步骤、权限及验收限制见 [INTEGRATIONS.md](INTEGRATIONS.md)。

## 日常流程

1. **提交材料**：完整正文、附件、来源名称、原文链接及原发布时间。链接只供回查，不会自动抓取网页。
2. **检查解析**：保留原文件；文字按段落或 PDF 页码展示。解析失败、表格或图片缺漏会提示补充与核对。
3. **生成草稿**：调用已配置 AI，或手工增加本人步骤。对照原文检查适用对象、本人期限、所需材料、办理责任与联系方式。
4. **本人确认**：只保存选中的步骤；责任不明、材料不齐和时间不确定的情况需要明确记录核实结果。不要把学院审核时间当成本人提交期限。
5. **跟踪事项**：筛选、搜索、修改、标记完成或取消。状态、个人备注、改期原因和版本历史会保存。
6. **安排日历**：导出 `.ics`，在目标设备导入。导出之后改期或取消会提示手动同步外部日历。

通知录入、行动草稿及待办编辑会自动暂存到当前账号。切换页面或刷新可恢复；附件选择在完整刷新后需要重新选择，界面会明确提示。暂存失败时保留本页内容并提供重试和下载入口；出现其他窗口的编辑冲突时不会覆盖新草稿。

误点任务状态后，提示中提供短时间的“撤回”；稍后也可以在“已完成”中恢复。珞珈小信使会在合适的位置陪你整理事项，“个人设置”可关闭轻声问候和小动作。页面尊重系统的减少动效设置。

## 当前能力和边界

| 项目 | 当前实现 |
|---|---|
| 资料输入 | 正文、PDF、DOCX、UTF-8 / GB18030 TXT / Markdown、CSV / XLSX、PNG/JPEG/WebP、MP4 / WebM；一次通知最多 5 份附件，每份 5 MB，正文及附件提取文字合计 10,000 字 |
| PDF | 最多 50 页；扫描件、加密 PDF 等明确返回限制，暂不包含 OCR |
| 原文核对 | 保存原件、页码／段落与引用；补件使旧草稿失效，已确认事项保留供逐项核对更新 |
| AI | 小米 mimo-v2.6-pro 多模态连续对话、通知结构化提取、引用核实、超时与失败反馈、账号每日调用次数上限 |
| 会话容量 | 每账号 100 个会话；每会话最多 12 份材料，其中最多 4 张图片；文字合计 10,000 字。超限明确返回错误 |
| 数据 | SQLite 持久化、账号隔离、版本冲突检查、重复确认幂等、操作历史、个人导出、预览后追加导入与通知级删除 |
| 维护 | 后台启动／停止／重启、健康检查、自动每日备份及手动备份、空目录恢复工具 |
| 日历 | 明确日期按全天事件，无擅自补 23:59；明确时刻按北京时间换算；稳定事件标识、修改版本、显式提醒时间 |

日历文件是一次导出快照。手机是否导入、是否允许提醒、锁屏后是否通知，需要在目标设备上验证；应用不会伪称已送达。QQ 仅在管理员配置且本人完成一次性绑定后接收主动发给机器人的单聊；公众号接口仅用于获授权发布账号。没有代办学校业务、自动登录校园系统或读取个人微信／QQ 历史的功能。

“日历与提醒”提供 Apple 日历、Google 日历、Outlook 及其他日历的折叠操作指引，并链接相应官方说明。没有文件导入入口的设备可对照待办手动添加日程；首次使用应先创建测试日程，验证时间、通知权限、关闭页面及锁屏后的提醒，再用于重要事项。

当前适合个人本机使用及有管理员维护的小规模部署。提供公开注册不等于已经完成校园规模上线验收。更大范围开放前应根据真实用户数完成容量测试、服务器恢复演练和运行监控。

测试证据和尚未验证的项目见 [TESTING.md](TESTING.md)。运行依赖已锁定在 `requirements.lock`，不需要 Node 构建前端，也不依赖外部 CDN。


## 互动回答与附件预览

简单问题保持文字回答。适合计算、计划、对比、数据展示的问题，可由模型组合白名单组件；参数、勾选、排序等交互在浏览器本地完成。回复按流逐步出现；格式错误只降级对应区块，已收到的文字和部分内容保留。图片与视频仅允许经宿主授权的资源，模型不能执行任意 HTML / JavaScript / CSS。

附件可以在材料和待办中按需展开：图片和视频使用浏览器原生预览，PDF / DOCX 按提取文字展示，CSV / XLSX 按表格分页展示。文字预览不保留 Office 或 PDF 的原始版式，表格公式不会执行，视频不会自动播放或发送给模型。重要信息应下载原件核对；旧 DOC / XLS 需先转换，扫描 PDF 暂无 OCR。

对话页保留单一顶栏，输入区随内容增高；侧栏可以沿整条分隔线拖动、折叠并重新打开。手机向下阅读时收起顶部和底部导航，上滑或短暂停留恢复。日历月视图、日周时间轴和移动课表按可用高度适配，长列表分页。

可在个人设置选择回答详细程度、风格和偏好，相关条件会传给现有模型调用；学号、联系方式不作为模型个人条件。资料导入只追加并先预览；不会覆盖现有账号数据。原始文件和互动快照不从 JSON 导出包自动恢复。

管理者可将 `.env` 中的 `GENUI_ENABLED=false` 并重启，以恢复文字接口；无需删除数据库或消息。架构、协议、安全及回滚说明在 [docs/genui](docs/genui/DESIGN.md)。
